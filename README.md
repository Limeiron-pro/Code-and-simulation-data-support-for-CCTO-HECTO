# Code-and-simulation-data-support-for-CCTO-HECTO

# CCTO–HECTO Potential Dataset

This dataset contains potential parameters, fitting code, DFT reference data, and molecular dynamics inputs and results for CaCu3Ti4O12 (CCTO) and (Ca0.25Sr0.25Bi0.25Na0.25)Cu3Ti4O12 (HECTO).

## 1. Potential parameters

- Initial potential P0 and optimized balanced potential PB.
- Buckingham interaction parameters and atomic charges.
- LAMMPS potential files and atom-type definitions.

## 2. Fitting code and data

- Python scripts, configuration files, and reference data for the initial fitting using 43 configurations.
- Python scripts, configuration files, and development data for subsequent parameter refinement using 84 configurations.
- The development dataset includes 2 reference structures, 66 displaced configurations, 8 shear configurations, and 8 thermal configurations.

## 3. Independent evaluation data

- Eight independent thermal configurations covering CCTO and HECTO at 300 and 900 K, with two configurations per material and temperature.
- DFT structures, calculation settings, OUTCAR files, and predictions from P0 and PB.
- Analysis scripts and numerical tables for force, stress, and relative-energy comparisons.
- The 1,920 pairs of atomic force components used for the force-comparison plot.

## 4. Molecular dynamics validation

- LAMMPS input files, atomic structures, potential files, and selected outputs for equilibrium structures, thermal expansion, elastic properties, and NVE energy conservation.
- Python analysis scripts and corresponding numerical results.

## 5. Occupancy configurations

- DFT input and output files for three 160-atom HECTO configurations with different A-site arrangements.

## 6. Figure and table data

- Numerical data for the independent-evaluation metrics and force-comparison plots.
- Structural, thermal, elastic, and energy-conservation results generated by the included analysis scripts.
